# jade-tea-assets

Public image host for Jade Tea Amazon listing assets. Amazon's Listings Items API
requires a publicly fetchable URL to set product images, so the files live here.
Everything in this repo is already public on amazon.com product pages.

`main/<ASIN>_MAIN.jpg` — clean pouch shots (2889x2889, white background) by April Blodgett, Aug 2026.
